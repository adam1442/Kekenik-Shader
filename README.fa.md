# ⬡ Kekenik Shader (کیکنیک شیدر)

**ادیتور شیدر مبتنی بر نود (Node-Based)، مستقل از موتور بازی‌سازی و تحت وب.**  
یک گراف شیدر بسازید و خروجی آن را برای **GLSL (WebGL2)**، **WGSL (WebGPU)**، **HLSL**، **Unity URP** و **Godot 4.x** دریافت کنید.

[**نسخه انگلیسی (English README)**](README.md) · [**دموی آنلاین (Live Demo)**](https://adam1442.github.io/kekenik-shader/) · [**راهنمای کاربری**](docs/USER_GUIDE.md)

## معرفی پروژه

**Kekenik Shader** یک ویرایشگر گرافیکی شیدر (Visual Shader Editor) است که به‌طور کامل در مرورگر اجرا می‌شود. هدف این ابزار این است که توسعه‌دهندگان بازی و آرتیست‌های تکنیکال بتوانند تنها با طراحی **یک گراف نود**، شیدرهای مخصوص **مدل‌های سه‌بعدی (3D)**، **اسپرایت‌های دوبعدی (2D Sprites)** و **افکت‌های ذرات (VFX / Particles)** را بسازند و بدون نیاز به بازنویسی، برای موتورهای مختلف خروجی بگیرند.

> **توجه (نسخه پیش‌نمایش اولیه `0.1.0`):** این پروژه در مرحله **Early Preview** قرار دارد. بسیاری از قابلیت‌ها هنوز نیازمند توسعه و تست بیشتر هستند و خروجی‌های Unity URP و Godot 4 هنوز روی تمام نسخه‌های این موتورها به‌صورت کامل تست نشده‌اند. جزئیات کامل در [`docs/KNOWN_ISSUES.md`](docs/KNOWN_ISSUES.md) مستند شده است.

## ویژگی‌های کلیدی

- **یک گراف، ۵ خروجی استاندارد:** تولید کد برای **GLSL ES 3.00 (WebGL2)**، **WGSL**، **HLSL**، **Unity URP (`.shader`)** و **Godot 4.x (`.gdshader`)**.
- **رابط کاربری حرفه‌ای و قابل چیدمان (Dockable UI):** پنل‌های شناور و قابل جابه‌جایی، میانبرهای صفحهکلید کامل و جستجوی سریع نودها با کلید `Space`.
- **بیش از ۱۸۰ نود آماده:** شامل نودهای ریاضی، بردار و ماتریس، انواع نویز (Simplex, Voronoi, Perlin, FBM)، اشکال SDF، پردازش رنگ و بافت، نورپردازی، جابه‌جایی رئوس (Vertex Displacement)، عمق صحنه (Scene Depth) و ذرات.
- **پشتیبانی از Subgraph، Portal، Reroute و Group:** امکان کپسوله‌سازی گراف‌ها در ساب‌گراف‌های قابل استفاده مجدد (`.kshadersub`)، پورتال‌های بی‌سیم و گروه‌های تاشو.
- **تعریف پارامترهای Material Inspector (بلک‌بورد):** تعریف متغیرهای ورودی (بازه عددی، اسلایدر، رنگ HDR، بافت پیش‌فرض و Keywordها) که مستقیماً در Inspector موتور بازی (Unity / Godot) نمایش داده می‌شوند.
- **پیش‌نمایش زنده سه‌بعدی، اسپرایت دوبعدی و VFX:** مجهز به نورپردازی، سایه، Bloom، Tone Mapping و امکان بارگذاری مدل‌ها (`.glb`, `.obj`, `.fbx`) و تکسچرهای دلخواه کاربر.
- **بهینه‌ساز IR و نقشه حرارتی هزینه (Cost Heatmap):** ساده‌سازی عبارات ریاضی، حذف کدهای مرده و نمایش هزینه محاسباتی هر نود.
- **کتابخانه ۳۹ نمونه شیدر آماده (Sample Library):** شامل نمونه‌های متنوع سه‌بعدی، دوبعدی و VFX با تکسچرهای رویه‌ای (Procedural).
- **خروجی بسته ZIP استاندارد:** شامل فایل‌های شیدر، مانیفست `parameters.json` و راهنمای اتصال در موتور مقصد.

## راه‌اندازی سریع (Quick Start)

پیش‌نیاز: **Node.js نسخه ۲۰ یا بالاتر**.

```bash
git clone https://github.com/adam1442/kekenik-shader.git
cd kekenik-shader
npm install
npm run dev
```

برای ساخت نسخه نهایی (Production Build):

```bash
npm run typecheck
npm run lint
npm run build
npm run preview
```
